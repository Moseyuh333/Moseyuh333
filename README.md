## what I actually do

I'm a contributing developer on **[OmniRoute](https://github.com/diegosouzapw/OmniRoute)** — a free, MIT-licensed AI gateway (352 providers, 1,200+ models, 65k★, 550+ contributors). My PRs landed across its **chaos mode** (parallel multi-model dispatch) and the **skill collection tooling** that feeds it — shipping features, fixing bugs, and keeping the build green.

When I'm not on the gateway, I build things end-to-end:

**Never-Been-Found** — a Rust anonymous-routing protocol (ML-KEM-768 + X25519 hybrid crypto, Kademlia DHT, 1-round-trip circuits, cover traffic). Research-grade MVP, 27 passing tests, designed to outrun onion routing on paper.

**Skill_collector** — collects, scores, virus-scans and installs AI agent skills from GitHub into agentic IDEs. Python + YARA, built for the OmniRoute ecosystem.

The rest is a healthy mix: Kotlin Android apps, Java full-stack with PL/pgSQL, x86 assembly, GDScript experiments, and the occasional HTML page when a portfolio demands one.
